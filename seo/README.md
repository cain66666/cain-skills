## Что изменено относительно оригинала

Два изменения: состав набора и перенаправление ссылок на выброшенные скиллы.

### 1. Состав набора

**Взято (9 из 11):**
`content-brief` · `eeat-audit` · `expert-interview` · `featured-snippet-optimizer` ·
`keyword-deep-dive` · `linkbuilding` · `page-audit` · `semantic-gap-analysis` ·
`topic-cluster-planning`

**Не взято (2):**

- `write-content` — заменён нашим `article`. Причина: оригинал пишет одну версию на
  одном языке. Наш пайплайн ведёт каждый язык независимо от факт-листа, пишет
  голосом конкретного автора по профилю `voice` и проходит гейт свежей сессией.
- `improve-content` — заменён нашими `humanize-ru` (русский) и `humanize-en`
  (английский). Причина: стилевые правила не переносятся между языками, нужен
  отдельный скилл на каждый.

Ничего из выброшенного не удалено из оригинала — если нужны именно они, ставьте
набор InhouseSEO целиком, скиллы совместимы и живут рядом.

## Что эти скиллы делают

Работают вживую: сами ищут в поиске, читают выдачу и разбирают конкурентов.
Ключи API, выгрузки и платные инструменты не нужны.

| Скилл | Что делает |
|---|---|
| `keyword-deep-dive` | Разбирает один запрос: выдача, интент, топ-3 конкурента, план на 90 дней |
| `content-brief` | Бриф под статью: интент, разрыв в контенте, структура, техчасть |
| `semantic-gap-analysis` | Чего нет у вас, но есть у тех, кто в топе |
| `topic-cluster-planning` | Кластеры тем и архитектура «хаб — спицы» |
| `page-audit` | Аудит страницы против трёх конкурентов из выдачи |
| `eeat-audit` | Оценка сигналов доверия и что конкретно чинить |
| `featured-snippet-optimizer` | Заточка под быстрые ответы и блоки выдачи |
| `linkbuilding` | Поиск доноров и работа со ссылками |
| `expert-interview` | Вытаскивает из автора экспертизу, которой нет в интернете |

## Как стыкуется с нашими

Эти скиллы дают **данные**: ключи, интент, конкурентов, разрывы, бриф.
Наш `article` принимает их на вход и дальше ведёт текст сам — факт-лист,
независимые языковые версии, голос автора, гейты, сверка фактов.

Порядок обычно такой:

```
keyword-deep-dive / content-brief  →  article  →  humanize-ru  →  gate  →  публикация
        (их)                            (наш)      (наш)      (наш)
```

`expert-interview` полезно прогнать **до** `article`: он достаёт из автора то,
чего нет ни у одного конкурента, и это становится лучшей частью факт-листа.
